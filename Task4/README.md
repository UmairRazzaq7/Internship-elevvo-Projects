# Power BI Desktop Dashboard Project

## 📌 Project Overview

This project demonstrates Business Intelligence (BI) dashboarding using Power BI Desktop. The goal is to transform a retail dataset into an interactive visualization tool that provides insights into revenue, product performance, and regional sales.

## 🛠️ Tools & Libraries

* Power BI Desktop – for data modeling and visualization

* Power BI Service – to publish and share the dashboard

## 📂 Dataset

Source: Superstore Sales Dataset (Kaggle)

The dataset contains details about orders, products, customers, sales, and regions.

## 📊 Dashboard Features

### KPIs (Key Performance Indicators):

* Total Revenue

* Total Sales by Category & Sub-Category

* Top-Selling Products

### Regional Analysis:

Sales by Region & State

### Interactive Visuals:

* Filters and slicers for region, product category, and time

* Drill-through for deeper insights

* Custom visuals for better storytelling

## 🚀 Publishing

The dashboard is published to Power BI Service and shared using the Publish to Web feature, making it accessible via a public link.
